About my project

My project is a website called TradeIt.com, which is a platform for buying, selling, and trading old video games. The first home page consists of two interactive elements, a dynamic welcome message for your name and an image gallery carousel with the LightGallery plugin.
The second page is the main data page, it contains the table for the array of objects which are individual games. It has a search function along with sort high to low/ low to high buttons, and also an add button with all necessary fields. For the extra feature I included an overall average price of the games currently listed on the table which changes with the search function.
Finally, this page consists of the add a comment and view comments sections. It also has a further two interactive elements which are an image rollover of a wireframe to the final page with an image slider plugin, and a show/hide button containing more before and after image rollovers.
